Getting started

Build from source on GNU/Linux, select a frontend, and load a Python configuration.

Dependencies and release build

The tested environment is Debian GNU/Linux with GCC 14.2, CPython 3.13.5, json-c 0.18 and Xlib. The declared requirements are C11, CMake 3.18+, CPython 3.10+ embedding development files and json-c 0.15+. Lower supported versions have not all been tested.

sudo apt-get update
sudo apt-get install build-essential cmake ninja-build pkg-config     python3-dev libjson-c-dev libx11-dev xfonts-base xvfb

cmake -S . -B build -G Ninja     -DCMAKE_BUILD_TYPE=Release     -DPython3_EXECUTABLE=/usr/bin/python3
cmake --build build -j
ctest --test-dir build --output-on-failure

Select the same Python installation for its interpreter and development library. A virtual environment's Python can otherwise cause CMake to discover mismatched components. Xvfb is only needed for GUI tests; the tests explicitly skip GUI execution when it is unavailable.

Choose the frontend

./build/cpymacs file.py
./build/cpymacs --nox file.py
./build/cpymacs -nw file.py
./build/cpymacs --batch
./build/cpymacs --no-python --nox

With DISPLAY set, the first command launches the separate cpymacs-gui executable. Otherwise it starts the terminal frontend. --nox, -nox, -nw and bare nox all force the terminal. GUI operation requires X11 or XWayland, not a native Wayland-only connection. An X11 connection failure is not a guarantee of automatic terminal fallback.

Compile without a GUI

cmake -S . -B build-nox -G Ninja     -DCPYMACS_GUI=OFF -DCMAKE_BUILD_TYPE=Release     -DPython3_EXECUTABLE=/usr/bin/python3
cmake --build build-nox -j
./build-nox/cpymacs --nox

This configuration does not discover or link Xlib. --no-python is different: it disables plugin execution at runtime, but the backend binary still links CPython.

Load the supplied development profile

./build/cpymacs --config examples/dotemacs.py example.py
./build/cpymacs --nox --config examples/dotemacs.py page.html.j2

Use C-x C-f to open a file, C-x C-s to save, C-g to cancel, and C-x C-c to quit. Modified buffers require confirmation. M-x accepts command names and TAB completes names. In a terminal, Alt is encoded as ESC followed by a key.

Persistent sessions

# Choose a private directory; do not use a shared, writable socket directory.
mkdir -p "$HOME/.cache/cpymacs"
chmod 700 "$HOME/.cache/cpymacs"

# Keep this foreground backend running in its own terminal.
./build/cpymacs --server "$HOME/.cache/cpymacs/editor.sock"     --config examples/dotemacs.py example.py

# Other terminals can attach either frontend.
./build/cpymacs --nox --connect "$HOME/.cache/cpymacs/editor.sock"
./build/cpymacs-gui --connect "$HOME/.cache/cpymacs/editor.sock"

M-x detach-client closes only that frontend. C-x C-c quits the shared editor. All clients share editing state, including point and the minibuffer. This is not collaborative editing or an independent-frame model. Configure the backend when starting it: connection mode rejects configuration options.

Install and relocate

cmake --install build --prefix "$HOME/.local"
export PATH="$HOME/.local/bin:$PATH"
cpymacs --nox

Installed plugins live under share/cpymacs/python; examples under share/cpymacs/examples; documentation under share/doc/cpymacs. Executable-relative discovery permits relocation of the whole prefix. CPYMACS_PYTHON_DIR deliberately overrides discovery. Do not point it at untrusted code.

GitHub Pages

For branch publishing, select your branch and /docs under Settings > Pages. For workflow publishing, select GitHub Actions and use the bundled .github/workflows/pages.yml. Its automatic trigger is the main branch; adjust it when your default branch differs. The source archive does not create or publish a repository.

PuTTY and terminal colours

The high-contrast terminal policy uses indexed-only automatic output in 0.1.2, fixing the unsafe RGB fallback from 0.1.1. Use --tui-colors=256 to force indexed colours or --tui-colors=mono to use terminal defaults and non-colour attributes. Details and limits are in Terminal colours and PuTTY.
