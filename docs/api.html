Python customization API

Trusted Python commands and hooks operate on the native buffer through a small, UI-independent interface.

Loading configuration

Import api from cpymacs. The backend loads bundled mode definitions, then the default config file, then repeated --config files in order. The default location is $XDG_CONFIG_HOME/cpymacs/init.py, or ~/.config/cpymacs/init.py. --no-user-config skips only the default user file. --no-python skips all Python execution. Config exceptions are reported without silently replacing native command behavior.

from cpymacs import api

def surround_selection(editor):
    selected = editor.get_selection()
    if selected:
        editor.replace_selection("(" + selected + ")")
    else:
        editor.insert("()")
        editor.run_command("backward-char")

api.add_command("surround-selection", surround_selection)
api.bind_key("C-c (", "surround-selection")

For a module next to your config file, explicitly add its trusted directory to sys.path before importing it. The config directory is not automatically a Python package directory.

import sys
from pathlib import Path
from cpymacs import api

sys.path.insert(0, str(Path(__file__).resolve().parent))
api.load_plugin("my_plugin")  # Calls my_plugin.install(api).

Position conventions

All ordinary API positions are zero-based UTF-8 byte offsets. Ranges are half-open: [start, end). Positions must lie on code-point boundaries. goto_character(position) instead takes a zero-based Unicode-code-point index. Python string indexing counts code points, not UTF-8 bytes; convert explicitly with len(prefix.encode("utf-8")). Interactive goto-char is one-based, so it is not interchangeable with the API.

Text and commands

APIContract
bufferReturns a fresh dictionary with id, name, path, mode, point, character_point, mark, size, revision, mark_active, modified, tab_width, indent_width and auto_indent. It is not a mutable native buffer handle.
pathA pathlib.Path or None for a non-file buffer.
pointRead/write UTF-8 byte offset. Out-of-range or mid-code-point positions fail.

insert(text)Insert at point, replacing an active region according to native insertion behavior.
replace(start, end, text)Replace a valid half-open byte range within the current command undo group.
set_text(text)Compute a common prefix/suffix replacement rather than permanently storing a second full document. The Python caller still owns its complete string.
get_selection()Return the active region, or an empty string if no active mark.
replace_selection(text)Replace an active region and return True; return False when mark is inactive.
goto_character(position)Move by zero-based Unicode code-point index.
add_command(name, callback)Register callback(editor). During invocation, argument_count and argument expose the requested count and optional string.
run_command(name, argument=None, count=1)Invoke native or registered Python commands, raising RuntimeError on failure.
bind_key(sequence, command, mode=None)Bind canonical tokens globally or for a named mode; mode-local bindings take priority.
status(message)Set the modeline/minibuffer status message.
open_file(path)Open or switch to a file buffer.
save_file(path=None, force=False)Save with native checks and hooks. force=True is an explicit overwrite decision.
log(name, text)Update a named read-only log buffer without switching the current editing buffer.
load_plugin(module_name)Import trusted module and call its install(api) function.

Native built-in names dispatch before Python commands. Registering a Python command with a native name is not an override mechanism. Use a new command name and rebind the key. Multiple mutations in one callback share its current command group; the API is not a general transaction that rolls back exceptions.

Supported options

OptionScope and accepted value
tab_widthBuffer-local integer 1..64; display width of a tab and default literal-space TAB insertion count.
indent_widthBuffer-local integer 1..64; indentation increment.
auto_indentBuffer-local boolean; native newline indentation policy.
read_onlyBuffer-local boolean; prevent editing.
line_numbersGlobal boolean; reserve a line-number gutter.

fontGlobal X11 font family/pattern string; a usable core font must exist.
font_sizeGlobal integer 1..64; actual font availability limits rendering choices.

Set with set_option(name, value). Unknown names fail. get_option(name) currently reads only keys exposed by the buffer dictionary; it is not a general getter for global settings. set_font(family="fixed", size=16) sets both font options. Buffer-local options do not automatically become defaults for all future buffers; apply them from a mode or an after_open hook.

Hooks

on(event, callback) registers callback(editor). Emitted events are after_open, before_save, after_save and text_changed. A failing before_save hook aborts saving. Other hook failures are reported. Reentrant event dispatch is suppressed; callbacks added during dispatch run on later events.

Hooks are synchronous and trusted. Do not kill or switch the current buffer while a native edit/save operation is using it. Do not call the native API from a background thread. There is no cross-thread synchronization or async plugin scheduler. Keep per-keystroke hooks bounded; a full-buffer Python transformation on every key defeats the native data structure.

Modes and themes

set_mode(name, syntax, kind, keywords="", builtins="") sets the current mode and a native lexical policy. Kinds are 0 plain text, 1 hash-comment/Python-like, 2 C-family, 3 markup, 4 CSS and 5 Jinja. Keyword and builtin lists are space-separated. This is not an arbitrary regex lexer or a semantic parser.

set_theme(name, colors) accepts ten RGB integers in this order: text, background, comments, decorators, strings, keywords, functions/builtins/tags, numbers, selection background and mode-line background. A theme is global across all modes and both clients, subject to display support.

Failure and trust

Plugin print output is redirected to stderr so stdout remains a valid protocol stream. The API validates native text ranges and UTF-8, but it is not a security sandbox. Python can access files, spawn programs and terminate the process. Run only code you trust.
