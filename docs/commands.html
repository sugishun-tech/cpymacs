Commands and key bindings

Implemented native command names and the default key map, with behavior boundaries made explicit.

A familiar key map is not full behavioral compatibility. Compatibility records differences in undo, search, prefixes, modes and window behavior.

Key notation

C- means Control and M- means Meta/Alt. Sequences are separated by spaces. A sequence such as C-x C-f is two chords. In a terminal, ESC followed by a key supplies Meta; the ambiguity timeout is 60 ms. C-h is help and the DEL byte is backward deletion. Terminal emulators may intercept certain chords before cpymacs receives them.

Prefixes and extended commands

C-u supplies a numeric argument, repeated universal arguments multiply by four, and M-0 through M-9 and M-- build an argument. Counts are bounded to prevent pathological execution. Not every advanced Emacs prefix form is implemented. M-x opens the command prompt; TAB completes registered names. M-g g prompts for a one-based line number, and M-x goto-char uses a one-based Unicode character position.

Selections, kills and history

C-SPC sets mark; move point and then use C-w or M-w. The kill ring keeps up to 60 entries. Consecutive kill commands append or prepend according to direction. M-y rotates the ring only after a yank. GUI clipboard yanks feed the native kill ring. Insertion, deletion, formatting and replacement have undo records, but grouping is not Emacs's grouping model.

Search and replacement

C-s/C-r perform case-sensitive literal incremental search. RET accepts; C-g cancels. Query replace asks for source and replacement, then accepts y, n, ! or quit. It does not implement regular expressions or case-preserving replacement. Use the exact prompt wording rather than assuming every Emacs search key works.

Files, buffers and panes

File and buffer prompts support TAB completion. Saving refuses stale-file overwrites and unconfirmed replacement of an existing target. force-save-buffer deliberately bypasses the external-change protection. kill-emacs exits without the normal modified-buffer confirmation and can discard work. Pane splitting is limited to eight uniformly divided panes in one orientation; a new orientation changes the flat layout, not a nested window tree.

Customization and extensions

C-x + and C-x - are cpymacs text-scale extensions, not GNU Emacs's meaning of those complete sequences. C-? requests explicit redo where the frontend can represent it; M-x redo works when the terminal cannot. M-x detach-client disconnects a frontend without quitting a persistent server. The optional .emacs profile adds C-c C-r formatting to Python/Cython and literal two-space TAB to web modes.
