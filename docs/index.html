Overview

A Linux text editor built around one native backend, not two competing GUI and terminal implementations.

Experimental, not a drop-in GNU Emacs replacement. Familiar keys and a defined subset of commands are implemented. Full command semantics, Lisp packages and complete major-mode engines are not. Read Compatibility before adopting it for daily work.

What runs where

C terminal frontend ----------+
                              +-- JSON Lines -- C backend -- native text store
C X11 GUI frontend -----------+                    |
                                                   +-- embedded Python plugins

The core, command dispatch, text storage, lexer, IPC and both frontends are C11. Python supplies customization, mode definitions, commands, hooks and formatter integration. A plugin never receives a GUI widget. The GUI process does not embed Python or link the editing core.

Start here

Build and launch, then try the editing commands. To reproduce the supplied development setup, load examples/dotemacs.py and consult the setting-by-setting port. Write new commands using the Python API, or connect a new frontend through the documented protocol.

Default behavior

TAB inserts four ASCII spaces. The optional .emacs profile overrides web-related modes to two literal spaces. UTF-8 is the supported file encoding. The frontend chooses X11 when DISPLAY is set; --nox forces the terminal. A GUI-free build does not require X11.

Terminal readability

Version 0.1.2 fixes legacy PuTTY red text and unwanted underlines by using conservative indexed-only automatic output. The high-contrast adapter, software cursor and monochrome mode remain available. It avoids dependence on default and basic ANSI colours without changing the GUI theme. See Terminal colours and PuTTY.

Evidence, not a speed slogan

The release includes randomized native text-store tests, black-box command and file tests, Xvfb GUI tests, PTY tests, sanitizer runs and reproducible benchmarks. See recorded verification and measured performance. There is no controlled benchmark establishing superiority over simplepypad or GNU Emacs.

Documentation hosting

This entire site is plain HTML and CSS with relative links. Open index.html directly, or publish the repository's docs/ directory using GitHub Pages. No JavaScript, external fonts, package installation or site build is required.
