Historical evidence and the earlier test gap

The 0.1.0 record and 0.1.1 record are retained with their original versions. The 0.1.1 model incorrectly assumed that unsupported RGB groups are always consumed together. Its passes therefore did not establish legacy PuTTY compatibility. The old XTerm comparison and screenshot are also retained under versioned names.

Not verified

The user's exact PuTTY release/fork was not established, and no Windows PuTTY executable was run. The old parser model is derived from source; it is not a full emulator or a Windows rendering test. Modern extension-switch tests and actual XTerm rendering are additional, separate checks.

The existing limits remain: no exhaustive multiplexer or physical-display matrix, GNU Emacs differential conformance test, editor-to-editor speed comparison, real formatter-version matrix, physical-desktop Japanese IME test, remote CI run or GitHub Pages deployment. See Compatibility and Safety.
