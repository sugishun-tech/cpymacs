Mode detection

The longest matching lowercased suffix wins, so .blade.php is a template instead of generic PHP, and .html.j2 is Jinja. normal-mode reruns detection. Mode aliases are named for familiar Emacs commands; their names do not load Emacs packages.

Highlighting model

The native scanner recognizes common strings, comments, numeric literals, keyword lists, tags and selected decorations. Python triple-quoted strings and C-family multiline comments carry lexical state between lines. Edits invalidate the state cache from the changed line. Colors work in the terminal and GUI through the same spans.

The scanner is not web-mode, js2-mode, tree-sitter or a Python AST. JSX/TSX/Vue/Svelte/Blade and embedded languages share simplified lexical policies. Complex nesting, language-specific regular expressions and semantic symbol categories can be colored inaccurately. No completion, linting, refactoring, language server or syntax validation is implied.

Write a plugin

# my_plugin.py
from datetime import datetime

def install(api):
    def timestamp(editor):
        editor.insert(datetime.now().isoformat(timespec="seconds"))
    api.add_command("insert-timestamp", timestamp)
    api.bind_key("<f5>", "insert-timestamp")

Import the module from your trusted config and call its install(api) function, or use api.load_plugin("my_plugin") after setting Python's import path. Commands receive no GUI or terminal objects. Use api.log and api.status rather than opening a Tk window.

Optional formatter dependencies

The example formatter uses executable discovery on PATH. It never runs a shell or installs missing tools. An available isort runs first with --quiet; an available autopep8 runs second with --in-place --ignore=E501. If both are missing, formatting is a no-op.

A temporary file is written beside the source when that directory is writable, otherwise in the operating system temporary directory. Cython uses a .pyx suffix. The original buffer is replaced only after every available process succeeds and its output passes validation. Each tool has a 30-second timeout and input/output is limited to 16 MiB. The command is synchronous; the backend is unresponsive while it waits. Formatter stdout/stderr capture is not a general sandbox for malicious tools.

Executable flags, ordering, failure, timeout, missing-tool behavior and invalid output were tested using controlled fake executables. Real isort and autopep8 package versions were not installed in the verification environment. Their handling of particular Cython syntax remains tool-dependent. Formatting is explicit, not an automatic before-save action.
